2.5 Implemented endpoints and behaviors
All protected under requireAuth.

A) Tasks (Firestore-backed)
- Routes: backend/src/routes/tasks.routes.js
- Endpoints:
  - GET /api/tasks/today
    - Fetches tasks by userId
    - Orders by dueDate asc
    - Filters for “today” (supports Firestore Timestamp or string/date)
    - Returns { tasks: [...] }
  - GET /api/tasks?priority=&category=&status=pending|completed
    - Filters by completed true/false when status is provided
    - Returns { tasks: [...] }
  - POST /api/tasks
    - Validates payload with taskSchema (zod)
    - Creates task doc (userId, title, description, priority, category, completed, dueDate)
    - Returns 201 { id }
  - PATCH /api/tasks/:taskId
    - Validates partial payload
    - Ensures task belongs to user
    - Updates provided fields; dueDate can be set to null
    - Returns { ok: true }
  - DELETE /api/tasks/:taskId
    - Ensures task belongs to user
    - Deletes doc
    - Returns { ok: true }
  - POST /api/tasks/:taskId/toggle
    - Flips completed boolean
    - Returns { ok: true, completed: next }

B) Planner (Gemini structured JSON)
- Routes: backend/src/routes/planner.routes.js
- Endpoint:
  - POST /api/planner/generate
    - Body: { goals: string, timezone?: string }
    - Calls plannerService.generateDailyPlan({ userId, goals, timezone })
    - Returns { plan: <json> }
- plannerService:
  - Calls aiService.generateText with JSON-only system instruction
  - normalizeJSON extracts first JSON substring then parses
  - Validates json.timeline is present/array
  - Attempts to store last plan in Firestore ai_memory (non-fatal)

C) Chat (Gemini + Firestore persistence)
- Routes: backend/src/routes/chat.routes.js
- Endpoints:
  - GET /api/chat
    - Lists recent conversations (summaries) from Firestore chats ordered by updatedAt desc (limit 10)
  - GET /api/chat/history?chatId=<id>
    - Returns { chatId, history } with ownership enforcement
  - POST /api/chat/message
    - Body: { message: string, chatId?: string }
    - If chatId exists: load thread + enforce ownership
    - Else: create new chat doc id
    - Builds prompt context from previous messages (if any)
    - Calls aiService.generateText
    - Persists messages array to Firestore (merge)
    - Returns { chatId, message: <aiText> }

D) Analytics (heuristics based on tasks)
- Routes: backend/src/routes/analytics.routes.js
- Endpoints:
  - GET /api/analytics/today
  - GET /api/analytics/weekly
- analyticsService:
  - Today:
    - Calculates productivity, streak, focusTimeHours heuristic, recentActivity (top 5)
    - Streak: consecutive days with at least one completed task updated in the day
  - Weekly:
    - Builds 7-day points array in JS based on dueDate match or fallback to updatedAt
    - avgProductivity, completionRate, overdueRisk heuristic
